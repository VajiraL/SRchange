Future LU compatible with HILDA+

From:https://doi.org/10.1016/j.oneear.2025.101525
Data: https://zenodo.org/records/15017066

Desciption quoted from source:
This archive contains downscaled global-scale future land use and land cover (LULC) projections that were generated for the paper 'High resolution land use maps from 1960 to 2100.' We provide global-scale future LULC projections that span the period from 2021 to 2100 with yearly temporal and 0.01° spatial resolution (approximately 1 km at the equator). The future LULC projections are harmonised with historic LULC data between 1960 and 2020 from the HILDA+ version 2b dataset, which is also provided in the files in this archive. The harmonised LULC maps include seven LULC categories: urban, cropland, pasture/rangeland, managed forest, unmanaged forest, unmanaged grass/shrubland, and sparse/no vegetation.
The downscaled future LULC projections were generated by downscaling outputs from the Land System Modular Model (LandSyMM) from 0.5° to 0.01° using the LandScaleR algorithm (LandScaleR). Future projections are provided for five Shared Socioeconomic Pathway and Representative Concentration Pathway scenarios: SSP1-RCP2.6, SSP2-RCP4.5, SSP3-RCP7.0, SSP4-RCP6.0, and SSP5-RCP8.5. We generated two downscaled products per scenario: one where LandScaleR was parameterised at the country-scale, meaning each country was downscaled using the optimum parameters for that country, and a second where the algorithm was parameterised at global scale, where each country was downscaled using the global-scale optimum parameter values.
The harmonised LULC maps are provided as GeoTiff files. Each file is named according to the corresponding future scenario and contains historic LULC between 1960 and 2020 from HILDA+ version 2b, and downscaled future LULC projections from 2021 to 2100 for the given scenario. The suffix of each file states whether LandSyMM was downscaled using country-scale ('country-f') or global-scale ('global-f') parameters.
We also provide the land cover outputs from the PLUM module of LandSyMM (see here for the PLUM code) that were downscaled to 0.01° resolution for all five scenarios in the 'PLUM_land_cover_outputs.zip' archive. Each individual 'LandCover.txt.gz' file gives the coordinates of 0.5° resolution grid cells and the projected area of each LULC class per grid cell in millions of hectares (Mha) for a specific year.

"country" variant for 4 SSP-RCP scenarios are added here.
Each tif file has 141 bands for years 1960-2100 in the order 1-141.

* File format: GeoTIFF
* Spatial resolution: 0.01 degrees (approximately 1 km at the equator)
* Temporal resolution: yearly
* Time period: 1960-2100
* Historic period: 1960-2020, data from HILDA+ version 2b (see https://doi.pangaea.de/10.1594/PANGAEA.921846 for HILDA+ version 1.0)
* Future period: 2021-2100, generated by downscaling future LULC projections from the Land System Modular Model (LandSyMM; https://landsymm.earth) using the LandScaleR algorithm (https://github.com/TamsinWoodman/LandScaleR; https://doi.org/10.1016/j.envsoft.2023.105826)
* Projection: WGS84 (EPSG:4326)
* Classes/categories:
    * 0 - Ocean
	* 11 - Urban
	* 22 - Cropland
	* 33 - Pasture/rangeland
	* 441 - Managed forest
	* 442 - Unmanaged forest
	* 55 - Unmanaged grass/shrubland
	* 66 - Sparse/no vegetation
	* 77 - Water
